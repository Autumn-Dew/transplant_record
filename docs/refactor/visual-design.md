# 视觉与动效设计方案（第二轮）

> 目标：把「配色 + 装饰类」升级为可辨识的**孤星式界面语言与动效语汇**。
> 原则：华丽感来自排版 / 层级 / 线条 / 编号 / 构图，不使用发光、粒子、扫光、动态背景。

## 1. 布局与视觉层级

| 层级 | 表现 | 页面示例 |
|---|---|---|
| 框架层 | 深空蓝黑标题栏 + 侧边导航；工业橙当前页标识条 | 全局 |
| 页头层 | 工业橙标识条 + 页面名 + 等宽编号副标题 + 细线分隔 | 每个页面 |
| 数据层 | 等宽数字、工程编号 `[01]`、状态标签（实线/虚线/斜纹区分三态） | 列表、卡片 |
| 操作层 | 零圆角按钮、hover 反白、危险操作多段保护 | 全部 |

三态（始终/自动/隐藏）用边框语言区分：实线 / 虚线 / 40% 透明 + 斜纹，无需读文字即可辨认。

## 2. 页面转场（按页面语义使用不同语法）

| 语法 | 用于 | 效果 |
|---|---|---|
| `mv-page-list` | 代肝代办 / 游戏管理（列表型） | 内容自上而下展开后归位（机械分段缓动） |
| `mv-page-form` | 新增记录（表单型） | 从左侧推入，字段就位 |
| `mv-page-doc` | 价格表 / 返图 / 数据管理（文档型） | 自上而下"框架展开"（clip-path 扫开） |
| `mv-page-quiet` | 设置 / 蓝图（低频型） | 仅淡入，避免频繁视运动 |

## 3. 高频交互动效（轻快，不阻塞）

| 场景 | 语法 |
|---|---|
| 完成一项今日代办 | 高亮一次（`mv-settle`）→ 该项右滑收束离场 → 剩余项归位 |
| 跳过 / 异常 | 状态标签扫过一次刻度（`mv-gauge`） |
| 进度数字变化 | 数字自下而上归位（`mv-data`） |
| 服务项目 / 游戏增删 | 列表项展开与收束（`mv-list` + `TransitionGroup`） |
| 导航切换 | 工业橙标识条从旧位置滑到新位置 |
| 危险操作多段确认 | 边框颜色按段推进（红 → 橙 → 紫），保持现有约定 |

## 4. 版式重排动效（预设切换）

切换价格表 / 返图预设时，画布播放一次「版式重组」：
元素先降透明度并轻微下沉 → 新排版生效 → 依次归位（stagger 26ms）。
动效只作用于**展示层**，不触碰业务数据。

## 5. 无障碍与性能

* 全局支持 `prefers-reduced-motion: reduce`（统一降级为近乎瞬时）。
* 只动画 `transform` / `opacity` / `clip-path`，不做布局抖动动画。
* 高频操作 < 200ms；页面级 300–420ms；模块级 220–280ms。
