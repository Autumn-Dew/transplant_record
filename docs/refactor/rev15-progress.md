# 第十五轮 — 视觉升级：两套主题各有一套构图语言 + 汇报排版跟随背景风格

这一轮不是给现有界面再贴一层装饰，而是把「孤星」与「P3R」拆成两套**独立的构图规则**：
同一个页面、同一份 DOM，换主题就换造型语言，不只是换颜色。

**硬约束（两套主题文件都写在文件头）**：不改任何布局尺寸。
两个 `theme-*.css` 里出现的 `position / left / top / width / height` 全部落在
**绝对定位的装饰伪元素**（`::before` / `::after`）上，或为伪元素提供定位上下文的
`position: relative`；不设置 `padding / margin / font-size / flex / display`。
所以切换主题不会让页面重排、不会改变列表密度、不会影响点击区域。

## 1. 设计令牌新增「构图层」

`global-theme.css` 四套主题各自补一组结构变量，让「面板 / 铭牌 / 线条」成为可复用的三级层次：

| 变量 | 作用 |
|---|---|
| `--surface-raised` | 承载面（列表、面板） |
| `--surface-sunken` | 凹陷区（工具条、小色块底） |
| `--surface-plate` | 铭牌（页头、统计带、卡片标题） |
| `--plate-fg` / `--plate-fg-dim` / `--plate-line` | 铭牌上的字与线 |
| `--rule-strong` / `--rule-soft` | 深 / 浅两档线条 |
| `--figure-ink` | 数字专用墨色 |
| `--band-cyan` / `--band-yellow` | 仅 P3R：方向性色块 |

深浅两套孤星、两套 P3R 都各自有**完整**的这组值，不是运行时算出来的。

## 2. 孤星：科研档案终端（新增 `theme-lone-star.css`）

七个章节，始终遵守「纸面 → 铭牌 → 细线」的三层纵深：

1. **应用框架**：标题栏为深空铭牌底 + 橙色收口线，左端 6px 装订块；侧栏右缘双线。
2. **页面封面头**：标题区左侧 10px 装订条（上段工业橙、其余细线），底部偏移细线。
3. **控制台**：工具条凹陷底 + 底部刻度带；工具栏第一个按钮是全页唯一实心橙按钮。
4. **数据铭牌带**：统计带为深色铭牌（视觉重心），数字等宽 800 字重、冷白。
5. **筛选与列表**：筛选标签细线框、选中项铭牌底 + 橙色内条；列表为更亮的承载面。
6. **弹窗**：侧边档案抽屉，装订条用绝对定位，不改内边距。
7. **次级页面**：蓝图 / 记录 / 数据管理各自有铭牌与线级区分。

## 3. P3R：几何平面海报（重写 `theme-p3r.css`）

八个章节，语言与孤星完全分开 —— 斜切、锐角、错位、方向性色块：

1. **应用框架**：标题栏底边整宽斜切色带（青蓝 → 主蓝 → 明黄）。
2. **页面头**：整宽斜切色块当海报主视觉，不靠边框靠色块分区。
3. **控制带**：凹陷底 + 底部斜切色带。
4. **数据方块阵列**：统计项做成方块阵列（首块青蓝底深蓝字，其余深蓝底白字）。
5. **筛选与列表**：筛选项裁角、行间细线、偶数行淡青底。
6. **弹窗**：顶部斜切带 + 左侧竖色带（皆绝对定位装饰）。
7. **次级页面**：逐页给同一套几何语言。
8. **动效**：斜向切入 / 方块归位，不循环、不发光，`prefers-reduced-motion` 下全部退化。

## 4. 每日汇报：排版跟着「背景风格」走

`ReportSheet.vue` 的画布按背景的 `style` 字段挂类名 `rp-style-{default|lone-star|p3r}`，
背景与排版成套出现，且与**当前应用主题无关**：

| 画布类 | 排版 | 导出安全性 |
|---|---|---|
| `rp-style-default` | 沿用原版式（老用户成品外观不变） | — |
| `rp-style-lone-star` | 装订脊 + 深蓝档头 + 双线装帧 + 深色托管信息带 | 只用渐变 / 边框 / 字号，不用 `clip-path` |
| `rp-style-p3r` | 整宽斜切标题带 + 明黄收口 + 蓝色卡片标题块 + 粗体数字 | 同上 |

背景色卡同步放大（76×46 → **84×58**），选中色卡再加一层描边：
斜切、圆环、刻度这些「构图差异」在小色块里也能看出来，不再只靠颜色区分。

## 5. 三条反馈的修复

### 5.1 孤星浅色下「代肝记录」统计字体太浅 —— 根因是字色与底色不配套

`.summary-strip` 的规则写的是深色铭牌底，但文件后面又有一条 `.wd-summary`
把**代肝记录页**的底色改成了浅色承载面（`--surface-raised`），而字色仍是铭牌色
（`--plate-fg` / `--plate-fg-dim`）—— 浅字压浅底，统计几乎看不见。

* `.wd-summary` 底改回 `--surface-plate`，与其它页同一块铭牌；描边同步换成 `--plate-line`。
* `.income-chip`（收入统计的小色块）是浅底却继承铭牌浅字，补上 `color: var(--text-primary)`。

实测（孤星 · 档案）：统计带底 `rgb(16,25,35)`、数字 `rgb(232,226,211)` / 800 字重、
收入小块 `rgb(224,216,200)` 底 + `rgb(20,27,34)` 字 —— 全部可读。

### 5.2 窗口顶部不要大改、不能遮挡标题

标题栏只换配色与结构线，**高度仍由原来的 32px + 原 border 决定**；
标题文本「代肝工作终端 · TRANSPLANT RECORD」完整可见。

但第一版仍有遮挡，根因是**伪元素的定位属性没复位**：

`page-common.css` 里 `.rc-title-bar::before` 和 `.local-header::before`
的基础样式是用 `left` / `top` 定位的（左端小竖条）。P3R 主题想把它们改成
「贴底色带 / 右下刻度带」，只写了 `right: 0; bottom: 0` ——
CSS 的规则是 `left` 与 `right`、`top` 与 `bottom` 同时有值且宽度/高度确定时，
**`left` / `top` 胜出**，于是：

| 元素 | 修复前实际几何 | 后果 |
|---|---|---|
| `.rc-title-bar::before` | `left:0 top:50% translateY(-50%)`，高 4px | 4px 色带**横穿窗口标题文字** |
| `.local-header::before` | `left:8px top:18px`，宽 38%、高 12px | 519×12 的横条**压在页面标题上** |

修法：改用 `right` / `bottom` 时把对方一并复位（`top: auto; bottom: 0`、
`left: auto; right: 0`），标题栏那条还要加 `transform: none`。
修复后实测：标题栏色带 `top: 26px / 高 4px`（贴底），
页面头刻度带 `left: 847px / top: 57.5px`（右下角留白区），都不再与标题相交。

> 以后的教训：**在主题里覆盖一个已有伪元素的定位时，必须写全 `left/top/right/bottom`**
> 四个方向（用 `auto` 显式复位），否则会被基础样式里没被覆盖的那两个方向抢走位置。

### 5.3 汇报主题风格与背景色卡

见第 4 节：三套排版按背景风格自动切换；色卡放大并强化选中态。
