# 第十二轮修正 — 七条反馈

## 1. 托管天数可增可减

上一轮把「改天数」限制成只能减，理解反了 —— 已全部撤销，现在**能加也能减**：

* `projectService.updateProject`：不再按原周期封顶
* 项目详情窗口：输入框去掉 `max`，去掉"只能减少"的提示
* 新增记录页（编辑态）：同样放开

加天数走「改天数」或「续费」都行（续费的差别是会额外记一笔收费）。

## 2. 代肝记录：整个托管周期完成后才统计

之前理解成「隐藏跳过/异常记录」，错了。现在改为按**项目周期是否结束**过滤：

```js
// 托管 → 已完成 / 已归档 / 已到期 / 已取消 才算结束；单次 → 完成即算
const done = isCompleted(p) || isClosed(p) || isExpired(p)
```

进行中的托管项目不再出现在代肝记录里，统计（总记录 / 已完成 / 收入）也只算已结束的项目。

## 3. 蓝图分组默认只展开第一个 —— 上次没生效，这次修好了

**根因**：`groups` 是 `ref`，挂载时还是空数组，`watch(..., { immediate: true })` 第一次就跑了，
`collapsedInit` 被提前置位，等分组真正加载完就不再做任何初始化 → 永远全部展开。

**修法**：不再用一次性标记，改为每次发现「新出现的组」就补上（第一个展开、其余收起），
已存在的不动，保留用户手动展开/收起。

UI 冒烟实测：2 个分组 → 1 个收起 ✓

## 4. 真实数据已全部删除

`testdata/` 里的 5 个真实数据文件、以及临时目录里的探针脚本**已全部删除**。核查结果：

| 位置 | 状态 |
| --- | --- |
| `testdata/`（项目内） | 已删除 |
| 临时探针目录 | 已删除 |
| git 历史（所有分支/标签） | 无任何 testdata 记录 |
| 当前 HEAD 树 | 无数据文件 |
| `dist/` 构建产物 | 无数据文件 |
| `.gitignore` | 保留 `testdata/` 规则，防止将来误加 |

原始数据仍只存在于你自己的 Electron 用户数据目录，不经过本仓库。

## 5. 设置页支持加载备份

「设置」新增 **加载备份**：选一个备份 JSON → 逐条写回 `tr-` 键 → 同步写回 Electron 文件（否则下次启动会被旧文件覆盖）→ 自动刷新。
属于危险操作，走 4 次点击确认（按钮会显示"再点 N 次确认"）。

## 6. 续费窗口换成详情窗口的版式

原来是一个 460px 的窄弹窗、输入框用 `form-select`。现在完全对齐「详细信息」窗口：

`edit-popup pd-popup` + `<h4>` + `.pd-head`（名称 / 服务 / 状态）+ `.detail-grid` 三段分组（原项目 / 本次续费 / 说明）+ `pd-inp` 输入框。

## 7. 所有侧边弹窗占页面一半宽度

`.modal-mask .edit-popup` 由固定 `560px` 改为 `50vw` —— 所有侧边弹窗统一生效。
UI 冒烟实测：窗口 1427px → 弹窗 714px ✓
