# 第十三轮修正 — 四条反馈

## 1. 续费窗口的字段并排显示

**根因**：续费窗口的 `.pd-head` / `.pd-name` / `.pd-sub` / `.pd-state` / `.pd-inp` 这套样式只写在
`ProjectDetail.vue` 的 `<style scoped>` 里；而续费窗口在 `AddPage.vue` 中，**拿不到 scoped 样式** ——
所以那些 `div` 只能按默认块级元素换行排列。

**修法**：

* 把 `.pd-*` 这套共用样式**提升到全局** `page-common.css`（详情窗口与续费窗口都能用）
* 续费窗口标题行改为一行并排：`终末地 | 基建更新 · 托管续期 | 续费`
  （`.renew-head-line` 用 `flex + nowrap`，中间用 `.renew-sep` 画 `|`）

## 4. 蓝图分组默认只展开第一个 —— 又是一个根因

上一轮改成"每次补新组"，但监听的对象错了：

* `groups`（`blueprintGroupsRepo.state`）是**手动排序用的分组列表**，没拖过排序就是**空数组**
* 真正的分组来自每条蓝图自己的 `group` 字段，由 `groupedRecords` 汇总出来

监听空数组当然永远不触发 → 全部展开。

**修法**：改监听 `groupedRecords`，每次发现「新出现的组」补上默认值（第一个展开、其余收起），
已存在的不动，保留用户手动展开/收起。

UI 实测：2 个分组 → 收起 1 个 ✓
