### 2.2 操作

| 操作 | 原版 | 当前 | 说明 |
|---|---|---|---|
| 编辑 / 保存 / 取消 / 关闭 | ✅ 有 | ✅ 保留 | 编辑只 patch 当前项目 |
| 删除（物理） | 列表行（3 段保护） | ✅ 保留（列表行）+ 详情内「删除」两段确认 | 有历史记录时不可删除 |
| 归档 | 列表行（删除流程会改为归档） | ✅ 保留 + 详情内「归档 / 取消归档」 | 归档只打标记，不改业务状态 |
| 确认完成 | 列表行 ✓ | ✅ 保留（列表行） | 本次未改动 |
| **暂停托管** | ❌ 无 | ✅ **新增**（`pauseProject`） | 服务层早已实现，此前无 UI 入口 |
| **恢复托管** | ❌ 无 | ✅ **新增**（`resumeProject`） | 同上 |
| **延期（顺延周期）** | ❌ 无 | ✅ **新增**（`extendProject`，可填天数） | 延期会按新周期重算计划次数 |
| **提前结束** | ❌ 无 | ✅ **新增**（`cancelProject`，两段确认） | |
| **续费** | ❌ 无（新增记录页有续费检测） | ✅ **新增**（`renewProject`，确认区可改起始日） | 起始日默认 = 原周期结束日**次日**，不静默覆盖 |

> 进入详情窗口前是"服务层有、界面无"的 8 个能力（暂停 / 恢复 / 延期 / 提前结束 / 归档恢复 / 连续托管历史 / 收入统计 / 取消代办）中的前 6 项，本阶段补齐了 6 项中的 5 项与历史查询中的执行记录部分。

### 2.3 新增的分区与视图

| 分区 | 内容 |
|---|---|
| 概览 | 基本信息 + 本期托管（周期/总天数/计划次数/执行进度/上次确认/暂停原因）+ 连续托管概要（第几期 / 连续区间 / 连续剩余 / 连续性）+ 锁定提示 |
| 托管周期 | 连续托管链总览 + **各期列表（可展开）**；展开后显示该期账号/游戏/服务与**该期自己的执行记录** |
| 执行记录 | 本项目全部执行记录（完成日期 / 结果 / 实际执行内容 / 备注 / 计划日期差异）+ 结果计数；空态说明"记录一旦生成即独立保存" |
| 财务 | 本期总收费/实际收费/延后收费/收费归属日 + 连续托管累计 + **逐期收费表**（各期收费与归属日独立） |
| 其他 | 平台名称 + 备注 + 档案标识（项目 ID / 上一期 / 托管链 / 归档时间） |

## 3. 实现

| 文件 | 作用 |
|---|---|
| `src/services/projectDetail.js` | **新增**：`buildProjectDetail()` 组装全部分区数据 + `availableActions()` 操作矩阵 + `periodFee()`。**只读** repository |
| `src/components/ProjectDetail.vue` | **新增**：分区抽屉（纯渲染 + 派发，不含业务规则）；打开/关闭/分区切换动效 |
| `src/views/AccountPage.vue` | 挂载新组件；操作事件接到 `projectService`；删除旧弹窗模板与不再使用的状态 |
| `tests/project-detail.test.mjs` | **新增**：14 个用例（操作矩阵 / 数据组装 / 历史隔离 / 结构约束） |
| `tools/ui-smoke.cjs` | 冒烟新增 18 项详情断言 + 7 张截图 |

**历史隔离**（§4.7）由设计保证：详情服务**只读**；编辑只 patch 当前项目（`updateProject` 按 id）；续费创建**新项目**（新 ID、独立收费与执行记录、不继承进度）。测试逐一断言：查看详情不写存储、编辑当期不改写其它期的资料/收入/执行记录。
